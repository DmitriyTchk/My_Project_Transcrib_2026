# VibeScribe Studio — Быстрый перезапуск (шпаргалка)

Короткая памятка: что делать, когда что-то остановилось. Подробности — в «Инструкции по развёртыванию».

## Обычная ситуация: ПК проснулся / перезагрузился

1. Запустите **Docker Desktop** (дождитесь зелёного «Engine running»).
2. Подождите 30–60 секунд — контейнеры `vibescribe-app` и `vibescribe-whisper` поднимутся **сами** (restart: unless-stopped).
3. Откройте http://localhost:3000.
4. Если не открылось — в терминале в папке `C:\Projects\VibeScribe`:
   ```
   docker compose up -d
   ```

## Проверка, что всё живо (10 секунд)

```
docker ps
```
Должно быть 2 контейнера со статусом `Up`:
- `vibescribe-app` → порт `0.0.0.0:3000->3000`
- `vibescribe-whisper` → порт `0.0.0.0:8000->8000`

## Если контейнер есть, но «мертв» (Exited)

```
docker compose up -d
```

## Если приложение открывается, но не видит Whisper

1. В приложении: Настройки → «Проверить связь».
2. Если красное — проверьте логи Whisper:
   ```
   docker logs --tail 50 vibescribe-whisper
   ```
3. Перезапуск только Whisper:
   ```
   docker restart vibescribe-whisper
   ```

## Если что-то совсем сломалось — «полный сброс»

```
docker compose down
docker compose up -d --build
```
Модель large-v3 НЕ будет скачиваться заново (она в Docker-томе).

## После обновления файлов проекта (новый архив/патч)

```
docker compose up -d --build
```
(пересоберётся только приложение, 2–5 минут)

## Полезно

| Команда | Что показывает |
|---|---|
| `docker ps` | Работающие контейнеры |
| `docker logs -f vibescribe-whisper` | Логи Whisper в реальном времени (Ctrl+C — выход) |
| `docker compose logs -f app` | Логи приложения |
| `docker compose down` | Остановить всё |
| `docker system df` | Сколько места занято Docker'ом |

## Вариант Б (без Docker для приложения)

1. Двойной клик `start-whisper.bat`
2. Двойной клик `start-windows.bat`
3. Окна не закрывать; http://localhost:3000
