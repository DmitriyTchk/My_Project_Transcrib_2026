# VibeScribe Studio — Инструкция пользователя

**Версия:** 06.09.2026
**Для кого:** для тех, кто пользуется приложением (без технических деталей установки)
**Запуск приложения:** откройте в браузере `http://localhost:3000` (на своём ПК) или адрес, который вам сообщил администратор

---

## Что умеет приложение

- **Транскрибация** аудио- и видеофайлов в текст (русский и другие языки) — на вашей видеокарте, без отправки данных в интернет
- **Таймкоды** для каждой фразы и подсветка текста при прослушивании (режим «караоке»)
- **Живая диктовка** голосом в реальном времени
- **Экспорт** результатов: TXT, субтитры SRT/VTT, JSON, CSV
- **История** всех расшифровок
- **Советник моделей** — помогает выбрать оптимальный движок распознавания
- **AI-функции** (при наличии API-ключа): краткое резюме, список задач, перевод

---

## Верхняя панель

| Элемент | Что делает |
|---|---|
| Логотип VibeScribe Studio | Показывает текущую модель распознавания |
| Вкладки | Транскрибация · Диктовка · Советник · Результаты · История · Настройки |
| Cloud API / Local GPU | Переключатель движка. **Local GPU** — распознавание на вашем ПК (рекомендуется, приватно). Cloud API — через облако (нужен API-ключ) |
| Иконка луны/солнца | Тёмная / светлая тема |

Внизу при прослушивании появляется **плеер**: Play/Pause, перемотка ±5 сек, ползунок, скорость 0.75x–2x и бегущая строка текущей реплики.

## Вкладка «Транскрибация» — основной сценарий

### Шаг 1. Выберите пресет (карточки сценариев)

| Пресет | Когда использовать |
|---|---|
| **Встреча и Совещание** | Совещания: таймкоды, спикеры, резюме, задачи |
| **Лекция и Вебинар** | Длинные записи: таймкоды + авто-резюме |
| **Интервью и Подкаст** | Диалоги: максимально точное разделение «Ведущий/Гость» |
| **Голосовая диктовка** | Быстро, без таймкодов, сразу в текст |
| **Субтитры для видео (SRT/VTT)** | Короткие интервалы для субтитров |
| **Privacy Mode (Только GPU)** | Максимальная приватность: всё локально, ничего не уходит в сеть |

Клик по карточке сам настроит все параметры ниже.

### Шаг 2. Загрузите файл
- Перетащите файл в зону загрузки или кликните для выбора
- Форматы: mp3, wav, m4a, ogg, aac, flac, wma, webm, mp4, mkv, mov, avi, ts
- **Большие файлы** (лекции на несколько часов, видео 1–2 ГБ) — тоже можно: они автоматически нарежутся на фрагменты на сервере, браузер не «зависнет»

### Шаг 3. Проверьте параметры (при необходимости)
- **Язык** — обычно «Русский» или «Автоопределение»
- **Таймкоды** — время начала/конца каждой фразы
- **Разделение спикеров** — подстановка «Спикер 1/2...» ⚠️ это приблизительное разделение (настоящее — в разработке)
- **Пунктуация, Резюме, Список задач, Перевод на английский** — по вкусу (резюме/задачи требуют облачного ключа)

### Шаг 4. Нажмите «Начать транскрибацию»
- Файл режется на фрагменты по 45 секунд, они распознаются последовательно
- Текст появляется в окне предпросмотра **по мере готовности** — можно читать сразу
- Ориентир по скорости: час аудио ≈ 5–8 минут на RTX 3060 Ti
- По завершении откроется вкладка **«Результаты»**

## Вкладка «Результаты»

- **Шапка:** имя файла, модель, длительность, число слов, язык
- **Резюме и задачи** (при наличии облачного ключа): тезисы + интерактивные чекбоксы задач; кнопка «Обновить анализ» — пересчитать после ручной правки текста
- **Два режима просмотра:**
  - *Посегментный* — реплики с таймкодами; **клик по таймкоду** перематывает плеер; **клик по тексту** — редактирование; **клик по имени спикера** — переименование сразу во всей записи
  - *Сплошной текст* — для чтения и копирования целиком
- **Поиск** — живой фильтр по словам и спикерам
- **Перевод** — выбор языка → «Перевести транскрипт» (таймкоды сохраняются)
- **Экспорт:** TXT (текст с метаданными), SRT и VTT (субтитры), JSON (для интеграций), CSV (для Excel)

## Вкладка «Диктовка»

1. Разрешите браузеру доступ к микрофону
2. Выберите режим: **классический** (клик — старт/стоп) или **Push-to-Talk** (говорите, пока зажата кнопка)
3. Говорите — текст появляется в реальном времени (серым курсивом — «в процессе», затем фиксируется)
4. Индикатор показывает уровень громкости микрофона
5. Дальше: «Копировать», «Очистить» или **«Сохранить как транскрипт»** — текст уйдёт в «Результаты»

> ⚠️ Диктовка на телефоне/другом устройстве работает только по HTTPS-адресу (ограничение браузеров).

---

## Вкладка «Советник»

Пошаговый опросник (тип задачи, оборудование, приватность, нужны ли таймкоды/спикеры) → карточка рекомендации с обоснованием, компромиссами и советом по настройке GPU → кнопка **«Применить рекомендацию»** сама настроит приложение.

## Вкладка «История»

Все прошлые расшифровки: открыть, скачать TXT, удалить запись, очистить всё (с подтверждением).

> ⚠️ История хранится в браузере (localStorage, лимит ~5–10 МБ). Длинные записи периодически выгружайте через экспорт (TXT/JSON) и удаляйте из истории.

---

## Вкладка «Настройки»

1. **Каталог моделей** — выбор активной модели распознавания. Рекомендуется: **faster-whisper (Large-v3)** — лучшее качество русского языка на вашей видеокарте
2. **Локальный GPU/Сервер** — адрес Whisper-сервера и его API-ключ + кнопка «Проверить связь» (должна быть зелёной перед работой)
3. **Секреты и API-ключи** — ключи облачных сервисов (Gemini, Groq, OpenAI, Deepgram). Хранятся только в памяти сервера текущей сессии, в браузер не возвращаются

## Типичные ситуации

| Ситуация | Что делать |
|---|---|
| «Не удалось подключиться к серверу» при проверке связи | Whisper-контейнер не запущен. Попросите администратора выполнить `docker compose up -d` (или запустите `start-whisper.bat`) |
| Первая транскрибация «висит» несколько минут | Скачивается модель large-v3 (~3 ГБ) — один раз, дальше будет быстро |
| В начале текста повторяется одна фраза много раз | Галлюцинация модели на тишине/заставке — удалите эти строки в редакторе |
| Спикеры чередуются механически | Это приблизительное разделение; точное (WhisperX) — в планах |
| Приложение не открывается | Запущен ли Docker Desktop и контейнеры (`docker ps`)? Подробности — в «Инструкции по развёртыванию» |
| ПК был в сне — приложение не отвечает | Запустите Docker Desktop, контейнеры поднимутся сами; через минуту обновите страницу |
