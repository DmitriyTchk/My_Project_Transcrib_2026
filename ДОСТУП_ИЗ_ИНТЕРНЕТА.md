# VibeScribe Studio — Доступ с других устройств и через интернет

**Дата:** 07.09.2026

Четыре способа открыть приложение не только на своём ПК. Рекомендуемый порядок: **A** (дома, уже работает) → **C** (основной для интернета, с паролем) → **B** (запасной, пока нет домена) → **D** (быстрый, временный адрес + скрипт уведомления).

---

## ⚠️ Перед выходом в интернет — включите пароль!

У приложения нет регистрации: кто знает адрес — тот пользуется вашей видеокартой. Поэтому для способов C и D **обязательно** включите пароль:

### Шаг 1. Создайте файл `.env` в папке проекта
В папке `C:\Projects\VibeScribe` скопируйте `.env.example` → переименуйте копию в `.env` (точка в начале — не ошибка).

### Шаг 2. Впишите пароль
Откройте `.env` Блокнотом, найдите и заполните:
```
APP_USER="admin"
APP_PASSWORD="ВАШ_НАДЁЖНЫЙ_ПАРОЛЬ"
```

### Шаг 3. Перезапустите приложение
```
docker compose up -d
```
Теперь при открытии адреса браузер будет спрашивать логин и пароль (один раз, потом запомнит).

> Если `APP_PASSWORD` пуст — пароль не спрашивается (удобно для localhost дома).

## Способ A. Домашняя сеть (уже работает)

Телефон/планшет в той же Wi-Fi сети, что и ПК:

1. На ПК: `ipconfig` → найдите «IPv4-адрес», например `192.168.1.50`.
2. На устройстве: откройте `http://192.168.1.50:3000`.
3. Если не открывается: Брандмауэр Windows → Правила для входящих → Создать правило → Порт → TCP → 3000 → Разрешить.

Ограничения: только дома; живая диктовка с телефона не заработает (браузеры требуют HTTPS для микрофона).

## Способ C. Cloudflare Tunnel — основной для интернета

Постоянный адрес с HTTPS. Два варианта:

### C1. Быстрый туннель (без домена, адрес временный)

Не требует ни аккаунта, ни домена:

1. Скачайте `cloudflared` для Windows: https://github.com/cloudflare/cloudflared/releases (файл `cloudflared-windows-amd64.msi`) и установите.
2. Запустите в терминале:
   ```
   cloudflared tunnel --url http://localhost:3000
   ```
3. В выводе появится адрес вида `https://xxxx-yyyy.trycloudflare.com` — открывайте его с любого устройства.

Минус: адрес **меняется при каждом запуске** (как у ngrok free). Для постоянного адреса — вариант C2.

### C2. Именной туннель (постоянный адрес, нужен свой домен)

1. Купите любой дешёвый домен (например, ~200–1000 ₽/год на reg.ru/nic.ru).
2. Добавьте домен в бесплатный аккаунт Cloudflare (cloudflare.com → Add site → смените NS-серверы у регистратора на выданные Cloudflare — инструкция на экране).
3. В терминале:
   ```
   cloudflared tunnel login
   cloudflared tunnel create vibescribe
   cloudflared tunnel route dns vibescribe vibescribe.ваш-домен.ru
   ```
4. Создайте файл конфигурации `C:\Users\<Имя>\.cloudflared\config.yml`:
   ```yaml
   tunnel: vibescribe
   credentials-file: C:\Users\<Имя>\.cloudflared\<ID-туннеля>.json
   ingress:
     - hostname: vibescribe.ваш-домен.ru
       service: http://localhost:3000
     - service: http_status:404
   ```
5. Запуск: `cloudflared tunnel run vibescribe`. Приложение доступно по постоянному адресу `https://vibescribe.ваш-домен.ru` (с паролем из `.env`!).

Плюсы: постоянный красивый URL, бесплатный HTTPS, диктовка с телефона работает.

## Способ B. Tailscale — запасной (личная зашифрованная сеть)

Самый безопасный: приложение вообще не видно в интернете — только ваши устройства.

1. Зарегистрируйтесь на https://tailscale.com (бесплатно, вход через Google/Microsoft).
2. Установите Tailscale на ПК и на телефон (есть приложения под всё), войдите в один аккаунт.
3. На ПК в консоли Tailscale (или в трее) посмотрите его IP вида `100.x.x.x`.
4. На телефоне откройте `http://100.x.x.x:3000` — работает из любой сети, хоть с мобильного интернета.
5. Для HTTPS (чтобы работала диктовка с телефона): в админ-консоли Tailscale включите MagicDNS и HTTPS Certificates, затем на ПК:
   ```
   tailscale serve --bg --https=443 http://localhost:3000
   ```
   Приложение будет доступно как `https://<имя-пк>.<ваш-tailnet>.ts.net`.

Пароль из `.env` здесь не обязателен (сеть и так только ваша), но не помешает.

## Способ D. ngrok — быстрый временный адрес + автоуведомление

У вас уже есть аккаунт ngrok. Проблема free-тарифа — адрес меняется при каждом запуске. Решение: скрипт **`ngrok-share.bat`** из папки проекта.

### Шаг 1. Запустите скрипт
Двойной клик по `ngrok-share.bat` (или в терминале из папки проекта).

Скрипт сам:
- запустит ngrok для порта 8000 (или проверит уже запущенный);
- заберёт новый публичный адрес;
- **сохранит его в файл `VibeScribe-адрес.txt` на Рабочем столе** (всегда);
- **отправит адрес вам в Telegram-бота** (если настроено, см. шаг 2);
- **отправит на e-mail** (если настроено, см. шаг 3);
- будет следить: если ngrok переподключится и адрес сменится — пришлёт новый автоматически.

Окно скрипта должно оставаться открытым. Закрыть — Ctrl+C.

### Шаг 2 (опционально). Telegram-уведомления
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → получите токен вида `123456:ABC-DEF...`.
2. Напишите своему новому боту любое сообщение.
3. Откройте **@userinfobot** → он покажет ваш Chat ID (число).
4. Впишите в `.env`:
   ```
   TELEGRAM_BOT_TOKEN="123456:ABC-DEF..."
   TELEGRAM_CHAT_ID="123456789"
   ```

### Шаг 3 (опционально). E-mail уведомления
Впишите в `.env` параметры SMTP вашей почты (пример для Gmail — нужен «пароль приложения», для Яндекса — пароль приложения тоже):
```
SMTP_HOST="smtp.gmail.com"
SMTP_PORT="587"
SMTP_USER="you@gmail.com"
SMTP_PASS="пароль-приложения"
SMTP_TO="you@gmail.com"
```

> ⚠️ Помните: ngrok-туннель ведёт на порт 8000 (Whisper API). Для доступа к **приложению** меняйте в скрипте/конфиге `NGROK_PORT="3000"`. Для работы приложения через туннель включите пароль (см. начало документа).
